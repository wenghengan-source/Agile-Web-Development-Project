# Smart Habit Tracker

## Overview
This project is a web application that helps users track daily habits such as exercise, diet, and routines.

## Features
- User registration and login
- Add and manage habits
- Track daily progress
- View statistics and streaks

## Tech Stack
- HTML
- CSS (Bootstrap CSS)
- JavaScript (later)
- Flask (backend - future)
