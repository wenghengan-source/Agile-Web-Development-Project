# Smart Habit Tracker – User Stories

1. As a user, I want to create an account so I can save my habits.  
2. As a user, I want to log in so I can access my habit tracker.  
3. As a user, I want to add a new habit so I can track it every day.  
4. As a user, I want to mark a habit as done so I can keep track of my progress.  
5. As a user, I want to edit or delete a habit so I can update my goals when needed.  
6. As a user, I want to see my habits for today so I know what I need to do.  
7. As a user, I want to see my streak so I can stay motivated to keep going.  
8. As a user, I want to get reminders so I don’t forget to complete my habits.  
9. As a user, I want to look back at my progress over time so I can see how I’m improving.  
10. As a user, I want to log out so my account stays safe and secure.
