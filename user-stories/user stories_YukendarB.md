## User Stories - YukendarB

- As a user, I want to view my habit statistics so I can understand my overall progress.
- As a user, I want to see my weekly habit completion so I can track my consistency over time.
- As a user, I want to identify my best and worst days so I can improve my routine.
- As a user, I want to receive insights about my habit patterns so I can make better decisions.
- As a user, I want the system to highlight habits I frequently miss so I can focus on improving them.
- As a user, I want to view my profile information so I can see a summary of my activity.
- As a user, I want to update my profile details so I can keep my account information accurate.
- As a user, I want to compare my progress with my friends so I can stay motivated.
- As a user, I want to view a leaderboard so I can see how I rank among other users.
- As a user, I want to view my habit completions on a calendar so I can track my daily activity easily.
